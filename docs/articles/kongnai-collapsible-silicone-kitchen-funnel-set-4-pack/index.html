How to use it

1. Pop the funnel open to its expanded shape. 2. Pick the size that matches the opening. Use a small funnel for narrow bottles and spice jars, and a large one for wider containers. 3. Pour slowly, especially with thin liquids, so the funnel does not overflow. 4. Rinse or run it through the dishwasher, then collapse it flat for storage.

A few practical ideas:

  • Color-code by job. With four colors, you can keep one for oils, one for dry spices, one for sweet things like syrup, and one for everything else.
  • Refill spice jars from bulk bags. The small funnels help direct dry spices into narrow openings with less waste.

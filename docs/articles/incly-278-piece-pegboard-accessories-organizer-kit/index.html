How to use it

1. Sort first. Before hanging anything, pull your tools off the bench and group them: hand tools, measuring and marking, power tool accessories, cords, and small hardware. 2. Plan the zones. Put the things you grab most at eye level near where you work. Heavier items go low, and rarely used tools go up high. 3. Match hooks to tools. Use straight hooks for wrenches and pliers, curved hooks for hammers and cords, L hooks for tape measures and levels, the ring holder for screwdrivers, and bins for screws, nails, and bits. 4. Lock them in. Use the included peg locks to keep hooks from popping out when you pull a tool off the board. INCLY notes that peg locks are what let the hooks fit 1/4 inch pegboard. 5. Leave room. Keep some open holes so you can add new tools later without rearranging everything.

A popular trick is to trace each tool's outline on the board with a marker once it is hung, so you can see at a glance what's missing.

How to use it

Start light. Remove some of the sandbags so each weight holds only one or two pounds, and add more as the exercises get easier. Keep the same number of sandbags in each weight so both legs work evenly.

Wrap the weight around your ankle, thread the strap through the D-ring, and fasten it snugly so it does not slide. Then try glute kickbacks on all fours, side-lying leg lifts, standing hip abductions, or bridges. Add them to a Pilates or barre routine at home for extra resistance on leg work.

For walking, keep the weight on the lighter side and focus on normal, controlled steps. Take them off and let them air out after sweaty sessions.

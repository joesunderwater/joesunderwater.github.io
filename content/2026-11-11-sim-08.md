A handbrake is a small add-on that changes how rally and drift cars feel. Instead of binding a keyboard key or a face button, you get a lever with travel, resistance, and a mounting position that can mimic a road-car or a horizontal rally handle. The MOZA HBP is a PC-focused sim racing handbrake built for that job, with a CNC aluminum body, a non-contact angle sensor, and adjustments for angle, height, and pull resistance.

## Who it's for

The HBP is for PC sim racers who want a dedicated handbrake for drift, rally, or other titles that benefit from a precise pull. It is not a console-licensed controller. MOZA designed it to mount on most racing rigs with an M6 bolt pattern, and to connect either over USB to the PC or to a compatible MOZA wheel base that has a handbrake port.

It is a fit if you already have a MOZA base such as the R5, or if you want a USB handbrake that can sit beside another PC wheel. For a desk setup without a cockpit, MOZA points to a Universal Mounting Plate (sold separately) rather than claiming the HBP clamps to a table on its own. A side-mount bracket is also listed as optional.

## Key features

Details below come from MOZA’s official support materials, user manual, and the Amazon listing for this ASIN:

- CNC-machined, aerospace-grade aluminum body with an anodized finish, in black on this listing.
- A non-contact high-precision angle sensor. MOZA’s support page and the Amazon listing for this model describe it as a 16-bit sensor, which avoids a wear-prone potentiometer in the sensing path.
- Dual-mode lever mounting: horizontal for a rally or drift layout, or vertical for a more road-car style. Height and angle are adjustable, and a multi-angle setup is officially supported.
- Adjustable pull resistance and travel by swapping springs and changing the stop position. The manual also includes a damper and damper spacers in the toolkit.
- Connection over USB directly to a PC, or to a compatible MOZA wheel base for simpler calibration in Pit House. The Amazon listing names compatibility with the R3, R5, R9 V2 New Edition, R12, R16, and R21 bases. MOZA support says it works with all MOZA wheel bases; confirm your exact base if it is a newer or older variant.
- In Pit House, you can set start and end points, adjust the output curve, calibrate the axis, and choose button (on/off) mode or axis mode with continuous travel.
- Official size is 153 x 68.3 x 365.5 mm, and the net weight is 0.7 kg. The bolt pattern is M6. The box includes the handbrake base, lever, toolkit, and data cables.

## How to use it

Mount the base to a rig plate or a compatible MOZA mount using the M6 holes, then set the lever to horizontal or vertical and tighten the height and angle once your hand can reach it cleanly. Connect USB to the PC, or use the wheel-base cable if you are staying inside the MOZA ecosystem. Open Pit House, calibrate the travel, and pick axis mode if you want a progressive pull for drift and rally, or button mode if a title only needs an on/off handbrake.

Swap the spring or adjust the stop if the lever feels too light or too long. A shorter, firmer pull is often easier to repeat in a rally stage; a longer pull can be useful when you want more modulation in a drift. After any mechanical change, recalibrate so the game sees a clean rest position and a clean full pull.

If you do not have a cockpit, use MOZA’s official desk-mounting accessories rather than improvising a weak clamp. Check the live listing for current cable types and included tools before you buy.

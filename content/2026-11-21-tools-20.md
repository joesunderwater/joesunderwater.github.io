## How to use it

Choose the bit that fits the screw head snugly and seat it in the driver. Twist the driver body to set the direction, loosening for stuck screws, then hold it firmly in the screw head, square to the work. Strike the back end with a hammer. Each blow drives the bit into the head while turning it a small amount, which helps keep it from camming out and stripping the screw further.

For stuck screws, start with a few firm strikes, then try to turn the fastener by hand once it breaks loose. Penetrating oil can help with rusted hardware, especially on cars and motorcycles.

If the head is already stripped, use the screw extractors. Drill a pilot hole with the drill bit size the listing recommends (5/32 inch for the #3, 1/4 inch for the #4), seat the extractor, and use the driver set to loosen to back the screw out.

Check the direction setting before each use. Wear safety glasses, since bits and fasteners can chip under impact.

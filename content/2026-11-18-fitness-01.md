## How to use it

Set both dumbbells on their bases, turn to the weight you want, and lift straight up. The brand says the handle locks the plates as soon as you pick it up. To change weight between sets, put the dumbbell back fully on its base first, then rotate. Never try to adjust a dumbbell while holding it.

A simple home routine could mix goblet squats, rows, presses, curls, and lunges. Start light to learn the movement, then move up a setting as each exercise gets easier. Because changes are quick, the set works well for drop sets or circuits that use different weights for different moves.

Keep the bases on a flat, stable surface, ideally on a mat, and return the dumbbells to them after every set so the plates stay organized.

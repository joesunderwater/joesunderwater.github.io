## How to use it

Lay the mat on a flat, even floor and connect it using the magnetic tracks. Put the ball storage box nearby so your balls stay organized between sessions.

Start with short putts at around 2 feet to groove a consistent stroke, using the gradient lines to check alignment. Then work back toward the 7.5-foot maximum. The automatic ball return sends each ball back to you, so you can hit putt after putt without stopping.

A few minutes a day, during a work break or before dinner, adds up. Try simple games: make a set number in a row from each distance before moving back, or alternate short and long putts to practice speed control.

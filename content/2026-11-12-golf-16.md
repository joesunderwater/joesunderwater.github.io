## How to use it

Lay the mat on a flat surface and connect the return track and magnetic ends according to the included instructions so the surface sits smooth. Start with the standard hole and use the 2- to 8-foot markings to practice specific distances. Place the mirror so you can see whether your eyes, head, and shoulders are set the way you intend, then make a stroke and watch whether the ball stays on the alignment guide.

Switch to the smaller hole when the larger one is no longer a challenge. The automatic return is most useful for made putts; missed putts will still need to be collected. Because the mat is only 10 inches wide, set it where a slight miss will not immediately roll under furniture, and avoid using it as a full-swing surface.

When you are done, disconnect the magnetic ends and store the mat and mirror together so the kit stays complete.
